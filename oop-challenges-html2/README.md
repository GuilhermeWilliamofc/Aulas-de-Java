# Desafios de Java POO Interativos

Este projeto é uma ferramenta interativa em HTML para testar e aprimorar seus conhecimentos em Programação Orientada a Objetos com Java.

## Funcionalidades
- **Editor de Código Simulado**: Sinta-se em um ambiente de desenvolvimento.
- **Micro-interações**: Feedback visual imediato para respostas corretas e incorretas.
- **Progresso Dinâmico**: Acompanhe seu avanço pelos 5 desafios fundamentais.
- **Foco em Conceitos**: Herança, Encapsulamento, Polimorfismo e muito mais.

## Como Executar
Abra o arquivo `index.html` em qualquer navegador moderno.
